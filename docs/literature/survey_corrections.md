# Proposed corrections to the literature survey CSV

Status: **on hold, not applied**. The maintainer has not accepted these rules yet, and has
declined the control-detector rule: values of a control or secondary detector stay in their
columns. The rows that followed that rule have been withdrawn. Each remaining change was checked
against the paper, and against released code where the text was ambiguous, by a reader who did
not write the proposal.
Next step: the maintainer checks a few of the changes against the papers before deciding on the
rest.
Row numbers are 0-based rows of `src/ripple_detection/data/literature_detection_parameters.csv`.

The Evidence column quotes the paper and gives its location: the section and the page of the
PDF, counted from the first page of the file ("printed p." marks the journal's own page number
where the reviewer noted it). Other papers are named when the evidence is in them. Code
locations are files in the authors' released code, which the paper's note, linked from the Row
column, identifies along with the paper's DOI.

## Rules the changes follow

Each detection column records the definition of the candidate events a paper decodes: the
detection rule, plus inclusion criteria applied to detected events before decoding (a minimum
number of active cells, a minimum event duration). Those inclusion criteria stay. Removed:

- **Unrelated part of the paper (U):** place-field speed filters, run segmentation, validation
  of a sleep scorer, criteria that label events after detection. A speed limit that defines the
  sleep or rest state in which events are detected stays (rows 22, 23, 26, 29).
- **Decoded-content criterion (Q):** lengths counted in decoding bins or decoded sequences.

"#N/A" means the paper has no such criterion; "Not reported" means the criterion exists but
its value is not given.
