# Krause 2022 — A large majority of awake hippocampal sharp-wave ripples feature spatial trajectories with momentum
Source: the extracted text (pdftotext of the Dropbox PDF, includes STAR Methods); title verified: yes (Krause & Drugowitsch, Neuron 110:1–12). Cited detection paper: scratchpad/papers/42_Pfeiffer_2015.txt. Code: Zenodo 10.5281/zenodo.5651913 (downloaded, see Code).
Trigger: SWR (SWRs detected by Pfeiffer & Foster 2015, then trimmed to the population burst inside each SWR). HSEs are a secondary trigger for a control analysis.

## Method as implemented

Main events (STAR Methods, "SWR and HSE detection" and "Extracting population bursts from SWRs", p. e2):
- Source of SWRs: "For our study, we used the set of SWRs identified in Pfeiffer and Foster (2015) based on features of the local field potential (LFP)." Results: "we used the 2,956 SWRs (Figure 1B) that Pfeiffer and Foster (2015) identified by their ripple-band power of the local field potential (mean ± SD = 372 ± 42 SWRs per session" (p. 2). Data: 40-tetrode CA1 arrays, "80–263 single units", 8 sessions from 4 rats.
- SWR rule (restated from Pfeiffer & Foster 2015): "a representative electrode was chosen for each tetrode, the LFP for that tetrode was band-pass filtered between 150 and 250 Hz, and the absolute value Hilbert transform of the filtered signal was smoothed with a Gaussian kernel (12.5 ms standard deviation). The average of this signal across all tetrodes was then used to identify SWRs as a local peak with an amplitude greater than 3 standard deviations above the mean, with start and end boundaries as the point when the signal crossed the mean. Only SWRs longer than 50 ms and shorter than 2 s that occurred when the rat was considered 'not moving' were included for further analysis."
- Speed: "the data was split in to 'moving' and 'not moving' periods by a threshold of 5 cm/s on the running speed" (Methods, "Data acquisition and behavior", p. e1–e2). Speed from 30 Hz position.
- Population-burst trimming (defines the analyzed event bounds; I count it as detection because every analysis uses these bounds): "we sub-selected a time period of each SWR in which the average firing rate across all neurons was above 2 spikes/s per neuron. Specifically, for each SWR, the spiking activity was binned using a 3 ms time bin ..., and the 'population burst' was defined as the period of time from the first upward-crossing to the last downward-crossing of the firing rate threshold within the SWR (Figure S7A). Population bursts shorter than 30 ms were excluded from the analysis (73 SWRs, or 2.5% of the 2956 total SWRs were excluded)." "Throughout all further analyses we only analyzed neural data within the extracted population burst, but referred to the extracted population bursts as SWRs".
- Minimum cells, merging of close events, theta or sleep criteria: not stated. Awake task sessions only.

Secondary events, HSEs (same section):
- "Following Pfeiffer and Foster (2013), a histogram of total spikes per non-overlapping 1 ms time bins was calculated and smoothed using a Gaussian kernel (20 ms standard deviation). HSEs were identified as peaks in the smoothed histogram greater than 3 standard deviations above the mean, with the starting point and end point of each HSE defined as the time point in which the smoothed histogram crossed the mean. Only time periods in which the animal was considered 'not moving' were included for further analysis."

Later analysis restrictions (not detection): only place cells (tuning-curve peak > 2 spikes/s) enter the state-space models; model comparison and trajectory classification are decoding-based.

## Inherited from
Pfeiffer & Foster 2015 (Science), supplementary "Local Field Potential Analysis": "For each tetrode, one representative electrode was selected ... Only tetrodes on which excitatory hippocampal cells were recorded were used, thus all LFP signals were recorded in the pyramidal layer. To examine SWRs, the LFP was band-pass filtered between 150 and 250 Hz, and the absolute value of the Hilbert transform of this filtered signal was then smoothed (Gaussian kernel, SD = 12.5 ms). This processed signal was averaged across all tetrodes and ripple events were identified as local peaks with an amplitude greater than 3 SD above the mean, excluding periods when the rat's velocity was greater than 5 cm/sec. The start and end boundaries for each event were defined as the point when the signal crossed the mean. SWRs shorter than 50 ms or longer than 2 s were excluded from further analysis." Krause's restatement matches. Whether the mean/SD come from immobile periods only is not stated in either paper.

## Code
https://github.com/DrugowitschLab/HippocampalSWRDynamics/tree/v1.0 (Zenodo 10.5281/zenodo.5651913), Python.
- SWRs are read precomputed from Pfeiffer & Foster's MATLAB files (`ratday_preprocessing.py`: `data["ripple_times_s"] = matlab_data.RippleTimes[:, :2]`); the code does not re-detect them or re-apply speed/duration limits (inference: already applied in the provided data).
- Population burst (`ripple_preprocessing.py::select_population_burst`, `config.py`): spikes of place cells only (`utils.get_spikemat(..., place_cell_ids, ...)`, divided by `n_place_cells`), 3 ms bins, smoothed by a 4-bin boxcar (`avg_fr_smoothing_convolution = [0.25]*4`, i.e. 12 ms), `> 2` spikes/s per cell, first to last supra-threshold bin, kept if `(end_timebin - start_timebin) >= ceil(30/3)`. The text says "all neurons" and does not mention the boxcar.
- HSE (`highsynchronyevents.py`): `gaussian_filter1d(spike_hist, 10)` on 1 ms bins, i.e. SD 10 ms, not the text's 20 ms; mean and SD over the whole session (`np.mean(spike_hist_smoothed)`), threshold mean + 3 SD (strict `>`), bounds to the last/next sample below the mean; HSEs partly in a run period are clipped to the rest period, fully in run dropped; then `hse_lengths > min_hse_duration_s` = 0.05 s (a 50 ms minimum not stated in the text). Rest = speed ≤ 5 cm/s (`run_boolean = velocity > 5`).

## Survey CSV discrepancies
No value in the detection fields contradicts the paper. Notes:
- MUA smooth (ms) 20 matches the text, but the code uses SD 10 ms (`gaussian_filter1d(..., 10)` on 1 ms bins). The MUA fields (3 SD, 20 ms) describe the secondary HSE analysis, not the main events.
- Detection "SWR, MUA": the main trigger is SWR; the MUA enters as the > 2 spikes/s/neuron population-burst trim inside each SWR and as the secondary HSE set.
- Detection Notes ">2 sp./s" omits the 3 ms bins, the first-up to last-down crossing within the SWR, and the 30 ms minimum on the trimmed burst (Min. Duration 50 ms is the SWR limit).

Remaining deviations:
- Channel combination: mean of Gaussian-smoothed Hilbert amplitudes (user code). Roumis would use mean of sqrt(smoothed squared envelope).
- Population-burst trim (3 ms bins, boxcar, > 2 spikes/s per place cell, first-to-last crossing, ≥ 30 ms) is user code; the package has no in-event trimming by a rate threshold.
- Speed: "not moving" (≤ 5 cm/s) is applied here to the event endpoints and to the normalization; the papers do not say whether the statistics were computed on immobile periods only.
- "Local peak greater than 3 SD" strict vs package `>=`; peaks sharing one supra-mean epoch become one event.
- Filter design unspecified in the papers (package: equiripple FIR, zero-phase).
- HSE: package smooths with a Gaussian of SD `smoothing_sigma` (use 0.020 per text or 0.010 per code); the code z-scores over the whole session (`normalization_mask=None`) and clips HSEs at rest-period edges, whereas the package's endpoint speed rule drops them.
Smallest package addition (if C): n/a. A helper that trims each event to the first/last bin where a supplied rate (or spike count) exceeds a threshold, with a minimum trimmed duration, plus a mean-amplitude channel combination option, would make this A.
