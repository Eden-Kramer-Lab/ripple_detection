## Method as implemented
STAR Methods, "SWR detection" (p. e5), verbatim:
- "To detect SWRs, the wide-band signal was band-pass filtered (difference-of-Gaussians; zero-lag, linear phase FIR), and instantaneous power was calculated by clipping at 4 SD, rectified, and low-pass filtered.32 The low-pass filter cut-off was at a frequency corresponding to p cycles of the mean bandpass (for 80-250 Hz band-pass, the low-pass was 55 Hz)."
- "Subsequently, the power of the non-clipped signal was computed, and all events exceeding 4 SD from the mean were detected. The events were then expanded until the (non-clipped) power fell below 1 SD; short events (< 15 ms) were discarded."
- "Sharp waves were detected separately using LFP from a CA1 str. radiatum channel, filtered with band-pass filter boundaries (5-40 Hz). LFP events of a minimum duration of 20 ms and a maximum of 400 ms exceeding 2.5 SD of the background signal were included as candidate SPWs. Only if a sharp wave was simultaneously detected with a ripple was a CA1 SPW-R event retained for further analysis."
- Not stated here: number of ripple channels, period for mean/SD, SW polarity, merging, state or speed restriction for detection. LFP at "1,250-Hz down-sampled signal".
- State scoring ("Detection of brain states"): buzcode SleepScoreMaster (Levenstein et al. 2019) — broadband-LFP PC1, theta ratio 5–10 / 2–16 Hz, EMG from 300–600 Hz inter-site correlation, "Soft sticky thresholds". Fully automatic as described.
- ANALYSIS, not detection (replay): "Replay events were identified from events with at least 5 active pyramidal cells with a peak firing rate of ≥1Hz and a peak-to-mean firing rate ratio of 1. In addition, candidate events with many (> 50%) inactive spike count bins were discarded." 20 ms bins. The 4 cm/s speed appears only for place fields and a movement control.

## Inherited from

## Survey CSV discrepancies
- Animal Speed = 4 cm/s: not a detection criterion in Harvey (place fields / movement control only). (FR 2019 used < 5 cm/s for ≥ 1 s; not restated here.)
- Min. Cells = 5: replay-analysis restriction, not detection.
- Max Duration = 400 ms: that is the sharp-wave maximum (20–400 ms); no ripple maximum is stated.
- SWR electrodes = 1: not stated (plus one radiatum channel; Oliva 2016 ran every site).
- SWR 4 SD, 80–250 Hz, min 15 ms: agree. Detection Notes agree with the text, but not with the code (DetectSWR k-means, or FindRipples without a radiatum channel on some datasets).

Recipe (text version):
```python
from ripple_detection.core import extend_threshold_to_mean
env = get_envelope(filter_ripple_band(pyr_lfp, fs, band=(80, 250)))[:, 0]
z = normalize_signal(gaussian_smooth(env, 0.003, fs))          # stand-in for clip/rectify/55 Hz low-pass
rip = np.asarray(extend_threshold_to_mean(z >= 1.0, z >= 4.0, time, 0.0))
rip = rip[rip[:, 1] - rip[:, 0] >= 0.015]
sw = user_filter(rad_lfp, 5, 40)                                  # radiatum, scipy band-pass
zs = normalize_signal(-sw)                                        # polarity: not stated
above = zs >= 2.5
sw_ev = np.asarray(extend_threshold_to_mean(above, above, time, 0.0))
sw_ev = sw_ev[(sw_ev[:, 1] - sw_ev[:, 0] >= 0.020) & (sw_ev[:, 1] - sw_ev[:, 0] <= 0.400)]
swr = require_overlap(rip, sw_ev)
```
Recipe (code, DetectSWR path): `Long_sharp_wave_ripple_detector(time, raw_pyr, speed, fs, sharp_wave_lfp=raw_rad, speed_threshold=np.inf)`, then the spiking filter below.
Recipe (code, FindRipples path, no radiatum): `Zugaro_ripple_detector(time, filter_ripple_band(pyr_lfp, fs, band=(100, 250)), speed, fs, speed_threshold=np.inf, low_threshold=1.0, high_threshold=3.0, minimum_inter_ripple_interval=0.050, minimum_duration=0.020, maximum_duration=0.300)`, then the spiking filter.
Spiking filter (eventSpikingTreshold, user code): `z = normalize_signal(rolling_60ms_count(pyr_spikes).sum(1) / n_units)`; keep events whose mean `z` within ±10 ms of `peak_time` is > 0.5.
Remaining deviations:
- No public DOG band-pass, 4 SD clipping, or rectify + 55 Hz low-pass power; Hilbert envelope + Gaussian smoothing substitutes.
- SW detection is user code (filter, polarity unstated); "simultaneously detected" = any overlap (`require_overlap`) is an interpretation.
- Mean/SD period unstated in Harvey (NREM in Oliva 2016/FR 2019).
- DetectSWR path: package departures listed in its docstring (seeded k-means, block handling, duration rounding); `check=True` manual curation and `useSPW=false` bounds (union of SW and ripple) are not available.
- FindRipples path: `EMGFromLFP` noise exclusion is not in the package; equiripple FIR vs bz_FindRipples' filter; bz_FindRipples' `durations(1)` merge semantics per the Zugaro docstring.
- eventSpikingTreshold's binning (`bz_SpktToSpkmat` overlap) reproduced only approximately.
Smallest package addition (if C): n/a. What remains without a radiatum channel: the ripple-power part of the text (4 SD peak, 1 SD bounds, ≥ 15 ms), the code's FindRipples path, and the spiking filter; the sharp-wave coincidence and DetectSWR cannot run.
