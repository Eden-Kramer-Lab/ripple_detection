# Testing Strategy

The suite, with its shared fixtures:

1. **[tests/conftest.py](conftest.py)** - Shared pytest fixtures: 1500 Hz LFP simulations with various ripple patterns, speed data (stationary and moving), multiunit spike trains, edge cases, the class-aware `time` and `stationary` fixtures, and `benchmark_import`, which puts examples/benchmark on `sys.path` for one test module and imports its modules by name
2. **[tests/test_core.py](test_core.py)** - Core signal processing: segmentation, extension, merging, the duration and gap boundary rules, normalization (including the degenerate-scale errors), filtering at several rates and across NaN gaps, envelope, smoothing, the Yu noise-threshold estimator; the event rules for building variants: speed rules, close-event variants (inclusive, peak, onset-measured), isolation, trace peaks and trimming, times inside events, windows around times, and the state thresholds (two-cluster, histogram minimum)
3. **[tests/test_detectors.py](test_detectors.py)** - One test class per detector plus shared classes for error handling, parameter ranges, input contents, participation, duration and speed conventions (unknown speed included), exclusion order, time ordering, the gap rule, and missing samples (short blocks included); the building blocks `detect_events_from_trace`, `detect_silence_bounded_events`, active-unit counts, spike-window trimming, `theta_delta_ratio` and `state_intervals`; a class states `FS` and `N_TIME` and gets `time` and `stationary` fixtures from conftest, and builds inputs with the helpers in [tests/_synthetic.py](_synthetic.py)
4. **[tests/test_simulate.py](test_simulate.py)** - Noise spectra, embedded ripples, per-ripple ranges, `ripple_snr`, and the inputs that used to give an all-NaN signal; the `SimulatedSession` fields' defaults and checks; the network simulator: `TestDrawNetworkEvents` (schema, components per type, rest and separation, rate, parameter locality, coupled strengths, validation), `TestSimulateNetworkSession` and `TestNetworkSessionVariants` (SNR, sharp waves, participants, spatial profiles, noise modulation, refractory spiking, chirp, burst envelopes, validation), `TestDrawNonEvents` (schema, where each kind occurs, rates, dropping spans that do not fit, drawn ranges at default and other settings, independence of kinds, validation), `TestNonEventRendering` (leaked spikes, their units and waveform, EMG, gamma SNR in its own band, theta bursts and the units they pick, id order, stream independence, validation), `TestTruthWindows` (the fraction formula, row order across fractions, crossings on the rendered envelope, network unions); hand-built events come from `_one_event_table` in this file, non-events from `_one_non_event_table` in [tests/_synthetic.py](_synthetic.py), which test_integration.py shares
5. **[tests/test_properties.py](test_properties.py)** - Hypothesis-driven invariants for the signal-processing functions
6. **[tests/test_snapshots.py](test_snapshots.py)** - Regression snapshots of detector output on fixed simulated data, and of a seeded network session's signals and spikes
7. **[tests/test_public_api.py](test_public_api.py)** - Pins `__all__`; the messages for calls written for 1.x; `llms.txt`'s example runs and names every detector
8. **[tests/test_registry.py](test_registry.py)** - Every exported detector is registered; each spec matches its signature by kind and position
9. **[tests/test_literature.py](test_literature.py)** - The shipped survey loads with the documented shape and types; README statistics match it; every DOI/column has evidence, paper/source links resolve, and artifact fingerprints are well formed. The separate dataset catalog has unique paper/deposit relationships, joins to surveyed DOIs, preserves unknown versus scoped-inspection statuses, and links to supporting notes; checks distinguish reused recordings, trial timing and code-only deposits from event data.
10. **[tests/test_integration.py](test_integration.py)** - Every detector driven by name from the registry on `simulate_session` output and judged against the ground truth: the registry path and the parameter set Spyglass stores, recall with a false-positive budget per detector, event bounds against the ripple windows, the filter-then-detect chain at 1000, 2000 and 30000 Hz, cross-detector agreement on one ripple, the output contract including the empty-result schema, scale and channel-order invariance, every public function that reads timestamps giving the same samples a day and a Unix time in (`TestTimeOrigin`; add a new one there), clipped flags at the recording edges, Long's seeding, and Yu's threshold under shared channel noise
11. **[tests/test_literature_recipes.py](test_literature_recipes.py)** - Every packaged default inventory through `examples/literature_recipes.py` runs on a short simulated session and returns events inside it; every surveyed paper has a recipe or a stated reason for none. Recorded demo options and baselines reproduce the Kaefer and both Ólafsdóttir configurations, and `examples/measured_walkthrough.py` runs
12. **[tests/test_literature_methods.py](test_literature_methods.py)** - Measured inputs, native bins, secondary inventories, kernel/boundary/merge distinctions, adaptive updates, artifact gaps with positive controls, normalization epochs, Unix timestamps, public-call parity, recording lifetime, constructor validation, a table of error paths, every method either raising without speed or ignoring it, bounds unchanged at a Unix clock origin, measured-data paths with curated inputs, each method's declared requirements (run with exactly them, and failing, by name, without each), `check_method`, the common output columns, diagnostics, `save_events`/`load_events` round trips, and Muessig curated-state versus optional sample-speed selection. These verify the implemented interpretations, not parity with unpublished historical event sets.
13. **[tests/test_evaluate.py](test_evaluate.py)** - `match_events` on hand-built cases (pair metrics, touching, zero-length events, optimal rather than greedy, more pairs before larger IoU, symmetry on tied grids, split and merge, `minimum_iou`, row positions, peak errors, `boundary_errors`, error paths), hypothesis invariants and a brute-force check that the assignment is the best one, `compare_detectors` and `consensus_counts` against hand values, `label_by_overlap` ties and index, and Kay against `truth_windows` on a simulated network session. The clock-origin case is in `TestTimeOrigin`
14. **[tests/test_benchmark_recipe_configs.py](test_benchmark_recipe_configs.py)** - The benchmark's configurations of the literature methods (examples/benchmark/recipe_configs.py) on a one-minute network session: configurations and exclusions partition `list_methods()`, each exclusion names exactly what `check_method` reports and the README lists it; every configuration passes `check_method`, equals the direct public call (frame and attrs) and records its resolved options by the package's JSON convention; ids, option invariants, hashing, stages, the reviewed primary-expression table and error paths, stale provenance included; the input policy (exactly the declared inputs, unit labels, rest intervals and a session without rest, `when` conditions, no stand-in for missing labels, no truth read; the ripple-inventory and demonstration-value stand-ins equal the package's simulation proxies, and the stand-in detectors run by their recorded names with every setting recorded and checked against settings pinned in the test); missing LFP samples inside a ripple, a Unix clock origin, recording lifetime, `method_record` and the assumptions; the package and the demo import no benchmark code
15. **[tests/test_benchmark_conditions.py](test_benchmark_conditions.py)** - The benchmark's simulation conditions (examples/benchmark/conditions.py): the 43 ids in order and the keys each factor and crossed cell sets; every condition simulates; `REFERENCE` names every simulator keyword and renders as the simulator's defaults; common random numbers on one-minute sessions (the same schedule, event times, baseline rates and participant draws across conditions that change no draw count, other stages untouched by the event rate); `factor_levels` with the reference in place; `select_conditions` (a crossed cell's id, unknown ids); the running schedule's bout and rest lengths; `resolve` and overrides, unknown keys, the JSON round trip through `parameters_from_json` (what a saved set lacks, a lost entry of a rate, unit-count or baseline mapping, a partial type mixture read as saved), a saved specification reproducing its session through `simulate_parameters`, and `REFERENCE_REVISIONS` holding the current values
16. **[tests/test_benchmark.py](test_benchmark.py)** - The benchmark runner (examples/benchmark/run.py) on 30 and 60 s sessions with a few methods: the sweeps and expressions as the contract states them, one record and one call per method and setting (Long's alias expanded, every tunable resolved, the input policy), sweep values and speed reaching the detectors (equal to direct calls), each table's columns and `read_table` keeping each table's text as text (the truth's event columns missing on non-event rows, an unknown file refused), scores equal to `match_events` and `boundary_errors` at every minimum IoU (a sliver matched only at 0), active-unit counts (a sub-sample event has none), rest with two bouts, a Unix clock origin, exact round trips of results (tuples, empty sessions) and of the truth with power-4 envelopes, local ripple channels and gamma sizing bands, failures and warnings recorded rather than raised (Gridchyn without a spike in its baseline; warnings while building a call's inputs) while an error building a recipe's inputs (a policy getter, the eligible epochs, the integer counts; Gridchyn without rest) or scoring raises, integer spike counts giving the float results; the command line with its report preflight stubbed and its git commit pinned: files written, `done.json` checks, resume (finished conditions kept byte for byte, interrupted or tampered ones rerun and printed, a changed specification, an unknown commit or a dirty tree refused before anything is written), the manifest's workers, `--combine` rebuilding `combined/` and naming the conditions it leaves out, a crossed cell's id, argument errors, the real preflight's messages, the smoke report with the validation's cost, a worker failure cancelling the queued sessions, two replicates on two workers in order with their seeds, and two workers writing what one does
17. **[tests/test_benchmark_validation.py](test_benchmark_validation.py)** - The simulator validation (examples/benchmark/validate_simulator.py): measurements on hand-built envelopes, spike trains and a noise-free ripple, at a Unix clock origin where timestamps are read (widths, participation counting units to the timestamps' rounding, silent gaps, inter-spike intervals, the RMS duration against its analytic crossing width, the refractory check's violations); target pooling (ripple duration from swr ripples alone, ratios, correlations) and readiness; which rendering checks apply to a condition (an unknown scope raises), and nothing measured or a NaN replicate failing one that does; a one-replicate reference report built with every detector, literature method and matcher made to fail: its spec (settings, seeds, hashes, parameter revisions), checks and their columns, measurements, and the targets recomputed from the measured samples; the command line's condition selection; the preflight (missing, failed, too few replicates, stale simulator, validator or target table, uncovered settings, tampered artifacts, every problem at once, the runner's own call on a ready copy) and the simulation fingerprint (detector edits leave it, simulation edits change it)
18. **[tests/test_benchmark_analyze.py](test_benchmark_analyze.py)** - The benchmark's analyses (examples/benchmark/analyze.py) on runs written by the test in the runner's schema through its own writer and scorer, two hand-built sessions, the second at a Unix clock origin: `paired_bootstrap` against the plain concatenating algorithm draw for draw, methods paired within a draw, replicates paired across conditions (an interval of exactly [1, 1]) and a session drawn twice counted twice; `sign_flip_test` exact and Monte Carlo, and its finite-pairs rule; the held-out split by replicate; the 1 MB limit, in `write_result` and stopping the command with the previous results kept; the main-analysis selection (defaults and recipes, not sweeps); a missing result counted as a failure, recorded or not; loading read back against the runner's own readers; matching again equal to the runner's scores, in parallel as in one process; false-positive labels, doublet splits and merges; and every analysis against hand values (the profile, consensus and its false-positive groups, false-positive classes, agreement, differences and the dendrogram, overlap, boundary errors with recall, paired timing on the shared true events only); the command's files and `summary.md`. No test draws a figure

The whole suite runs in seconds; `pytest` reports coverage of `src/ripple_detection` with the missing lines. The package also validates that example notebooks run without errors in CI.
