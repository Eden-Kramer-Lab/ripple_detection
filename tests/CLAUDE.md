# Testing Strategy

The suite, with its shared fixtures:

1. **[tests/conftest.py](conftest.py)** - Shared pytest fixtures: 1500 Hz LFP simulations with various ripple patterns, speed data (stationary and moving), multiunit spike trains, edge cases, and the class-aware `time` and `stationary` fixtures
2. **[tests/test_core.py](test_core.py)** - Core signal processing: segmentation, extension, merging, the duration and gap boundary rules, normalization (including the degenerate-scale errors), filtering at several rates and across NaN gaps, envelope, smoothing, the Yu noise-threshold estimator; the event rules for building variants: speed rules, close-event variants (inclusive, peak, onset-measured), isolation, trace peaks and trimming, times inside events, windows around times, and the state thresholds (two-cluster, histogram minimum)
3. **[tests/test_detectors.py](test_detectors.py)** - One test class per detector plus shared classes for error handling, parameter ranges, input contents, participation, duration and speed conventions (unknown speed included), exclusion order, time ordering, the gap rule, and missing samples (short blocks included); the building blocks `detect_events_from_trace`, `detect_silence_bounded_events`, active-unit counts, spike-window trimming, `theta_delta_ratio` and `state_intervals`; a class states `FS` and `N_TIME` and gets `time` and `stationary` fixtures from conftest, and builds inputs with the helpers in [tests/_synthetic.py](_synthetic.py)
4. **[tests/test_simulate.py](test_simulate.py)** - Noise spectra, embedded ripples, per-ripple ranges, `ripple_snr`, and the inputs that used to give an all-NaN signal
5. **[tests/test_properties.py](test_properties.py)** - Hypothesis-driven invariants for the signal-processing functions
6. **[tests/test_snapshots.py](test_snapshots.py)** - Regression snapshots of detector output on fixed simulated data
7. **[tests/test_public_api.py](test_public_api.py)** - Pins `__all__`; the messages for calls written for 1.x; `llms.txt`'s example runs and names every detector
8. **[tests/test_registry.py](test_registry.py)** - Every exported detector is registered; each spec matches its signature by kind and position
9. **[tests/test_literature.py](test_literature.py)** - The shipped survey loads with the documented shape and types; README statistics match it; every DOI/column has evidence, paper/source links resolve, and artifact fingerprints are well formed
10. **[tests/test_integration.py](test_integration.py)** - Every detector driven by name from the registry on `simulate_session` output and judged against the ground truth: the registry path and the parameter set Spyglass stores, recall with a false-positive budget per detector, event bounds against the ripple windows, the filter-then-detect chain at 1000, 2000 and 30000 Hz, cross-detector agreement on one ripple, the output contract including the empty-result schema, scale and channel-order invariance, every public function that reads timestamps giving the same samples a day and a Unix time in (`TestTimeOrigin`; add a new one there), clipped flags at the recording edges, Long's seeding, and Yu's threshold under shared channel noise
11. **[tests/test_literature_recipes.py](test_literature_recipes.py)** - Every packaged default inventory through `examples/literature_recipes.py` runs on a short simulated session and returns events inside it; every surveyed paper has a recipe or a stated reason for none. Recorded demo options and baselines reproduce the Kaefer and both Ólafsdóttir configurations
12. **[tests/test_literature_methods.py](test_literature_methods.py)** - Measured inputs, native bins, secondary inventories, kernel/boundary/merge distinctions, adaptive updates, artifact gaps with positive controls, normalization epochs, Unix timestamps, public-call parity, recording lifetime, constructor errors and Muessig curated-state versus optional sample-speed selection. These verify the implemented interpretations, not parity with unpublished historical event sets.

The whole suite runs in seconds; `pytest` reports coverage of `src/ripple_detection` with the missing lines. The package also validates that example notebooks run without errors in CI.
